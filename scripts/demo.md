# Script de démonstration (répétition ~8 min)

1. Lancer `uvicorn` (voir README). Navigateur : accueil, 4 temps.
2. Inscription : Sara El Amrani / mot de passe de démo / formule Entretien garanti / consentement coché.
3. Profil : poste « développeur python », ville « Casablanca ». Import `backend/data/sample_cvs/cv_sara.docx`.
4. Montrer compétences extraites, corriger si besoin.
5. Offres : pointer le score, les compétences communes, une offre peu pertinente en bas de liste.
6. Créer candidature sur Python junior → Générer lettre → souligner qu’on ne voit que des faits du CV.
7. Enregistrer, marquer envoyée (message « simulation pédagogique »).
8. Statut → entretien. Revenir aux offres / nouvelle candidature : erreur d’arrêt.
9. Journal : `inscription`, `import_cv`, `lettre_generee`, `agent_arrete`.
10. Formules : basculer sur Découverte et expliquer les quotas.
11. (Si le temps) suppression de compte.

Si le RSS est hors-ligne, le jeu `offres_demo.json` suffit (risque identifié dans la fiche technique).
